Handlungsempfehlungen
Kritische Punkte

Folgende Aspekte sollten vor der Installation einer Wärmepumpe beachtet werden:

  • Die Heizkörper im Badezimmer sind für Niedertemperatur-Betrieb nicht ausreichend dimensioniert.
  • Die Dämmung der Außenwand im Schlafzimmer ist schwächer als im Rest des Gebäudes.
Empfohlene Maßnahmen
  1. Heizkörpertausch im Badezimmer
    Ersetzen Sie den vorhandenen Heizkörper durch einen größeren oder einen Niedertemperatur-geeigneten Typ.
  2. Dämmung der Außenwand im Schlafzimmer prüfen
    Eine zusätzliche Dämmung könnte die Effizienz der Wärmepumpe verbessern.
  3. Hydraulischer Abgleich
    Für eine optimale Wärmeverteilung im gesamten Heizsystem.
