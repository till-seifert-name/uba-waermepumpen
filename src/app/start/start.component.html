UBA Wärmepumpen Tool

Beratung zur Auswahl und Installation von Wärmepumpen

Mit diesem Tool können Sie herausfinden, ob Ihr Gebäude für den Einsatz einer Wärmepumpe geeignet ist.

Sie erhalten Empfehlungen zu notwendigen Maßnahmen und Hinweise zur effizienten Umsetzung.

Gebäudedaten

Erfassen Sie grundlegende Informationen zu Ihrem Gebäude wie Bauart, Baujahr und Heizsystem.

Raumdaten

Geben Sie Details zu wichtigen Räumen an, um die erforderliche Heizlast zu ermitteln.

Ergebnis

Erhalten Sie eine Bewertung der Eignung Ihres Gebäudes für eine Wärmepumpe und Empfehlungen.
