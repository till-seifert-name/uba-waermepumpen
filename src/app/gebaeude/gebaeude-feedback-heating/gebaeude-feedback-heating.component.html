Super, Sie haben alle Gebäudedaten erfasst!

Ihr bisheriges Heizsystem enthält kein Wärmeverteilsystem und keine wasserführenden Heizkörper. Diese sind für die Installation einer Luft/Wasser- oder Sole/Wasser-Wärmepumpe notwendig. Für die nächsten Berechnungsschritte können Sie einfach so tun, als ob schon wasserführende Heizkörper installiert wären.

Hinweis:

Wählen Sie hierfür bei der Eingabe der Heizkörper jeweils einen Flachheizkörper, Senkrechtprofiliert vom Typ 33 aus und geben Sie bei der Abfrage der Abmaße den in der Heizkörpernische / unter dem Fenster potenziell verfügbaren Platz an. Ziehen sie hierfür jeweils 25 cm von der Fensterbreite und von der Brüstungshöhe ab.

Fensterbreite - 25 cm | Brüstungshöhe - 25 cm

Wenn Sie diese Einschränkungen berücksichtigen, können Sie das Tool weiter anwenden. Die Ergebnisse stellen dann nicht den Ist-Zustand Ihres Gebäudes dar, sondern eine mögliche Umrüstung des Gebäudes auf wasserführende Flachheizkörper.

Tipp: Sollten Sie die Umrüstung auf ein wasserführendes Heizsystem planen, empfiehlt es sich – insbesondere im Mehrfamilienhaus – auch die Option einer Umstellung der Trinkwarmwasser-Bereitstellung auf dezentrale Frischwasserstationen zu prüfen. Hierdurch wird die Temperaturanforderung an die Wärmepumpe verringert und somit die Gesamteffizienz verbessert.

Tipp: Unter Umständen kann die Umrüstung auf raumweise Luft-Luft Wärmepumpen für Sie eine Alternative zum Umstieg auf eine Wärmepumpen-Heizsystem darstellen.
