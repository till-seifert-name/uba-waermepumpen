🚧 Hinweis: Kein wasserführendes Heizsystem erkannt

Super, Sie haben alle Gebäudedaten erfasst!

Ihr bisheriges Heizsystem enthält kein wasserführendes Wärmeverteilsystem (z. B. klassische Heizkörper oder Fußbodenheizung). Solche Systeme sind jedoch notwendig, wenn Sie eine Luft/Wasser- oder Sole/Wasser-Wärmepumpe einsetzen möchten.

🔄 Was Sie jetzt tun können:

Sie können das Tool trotzdem weiter nutzen – indem Sie eine mögliche Umrüstung auf wasserführende Heizkörper simulieren.

👉 So funktioniert's:
  • Wählen Sie bei der Heizkörper-Eingabe einen Flachheizkörper, senkrecht profiliert, Typ 33 aus.
  • Geben Sie bei den Abmessungen den verfügbaren Platz in der Heizkörpernische an (z.B. unter dem Fenster).
  • Ziehen Sie dabei jeweils ca. 25 cm von der Fensterbreite und der Brüstungshöhe ab, um realistische Einbaugrößen zu schätzen.

⚠️ Wichtig: Die Ergebnisse stellen dann keinen Ist-Zustand dar, sondern eine mögliche Umrüstungsvariante.

Zusätzliche Hinweise zur Planung

Mehrfamilienhaus? Wenn Sie ein wasserführendes Heizsystem nachrüsten, prüfen Sie auch die Möglichkeit, die zentrale Warmwasserbereitung auf dezentrale Frischwasserstationen umzustellen.

→ Das senkt die Temperaturanforderung und verbessert die Effizienz der Wärmepumpe.

Alternative Lösung: Unter bestimmten Bedingungen kann auch die Umrüstung auf raumweise Luft-Luft-Wärmepumpen eine sinnvolle Option sein – etwa in Gebäuden ohne bestehende Wasserverteilung. Bedenken Sie hierbei, dass dann eine separate Lösung für eine effiziente Warmwasser-Bereitstellung erforderlich ist, beispielsweise mittels einer zentralen Trinkwarmwasser-Wärmepumpe.
